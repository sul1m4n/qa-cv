How I test

From requirement to verified fix.

01 / Understand

Clarify expected behavior, risks, data and integrations before testing.

02 / Validate

Test user flows, negative cases, API behavior and data where relevant.

03 / Report

Document reproducible defects with useful context for the team.

04 / Verify

Confirm fixes and check that surrounding behavior remains stable.
