Selected QA cases

Evidence, not just a skill list.

01 / Critical backend defect

Employee management was unavailable for a franchise user.

Reproduced the employee-service error on a QA company with a comparable role and captured the API response, error code and screenshots.

Result: After the hotfix, retested employee listing and creation; both passed, and the production update was confirmed the same day.

02 / SQL-related investigation

A report failed only after switching the interface language.

The transaction report opened in one interface language but failed after switching to another localized interface. I could not reproduce it on my QA company, so documented that fact rather than guessing a cause.

Result: A missing database object tied to the locale was fixed; the report then opened in both languages.

03 / Expected behaviour

A duplicated catalogue item did not retain the original price.

Before creating a development ticket, I clarified the behaviour with the development team and confirmed that manual pricing after cloning was intentional.

Result: Closed as expected behaviour, avoiding a false development task and saving team time.

Real example / database investigation
